# Changelog

## 1.0.0 — 2026-11-25

Initial public Firefox release.

- Per-tab auto refresh with 1–86,400 second intervals.
- Quick presets: 5 s, 10 s, 30 s, 1 min, 5 min, 15 min.
- Random interval mode with minimum and maximum delays.
- Live countdown badge, progress ring, next refresh time, and reload counter.
- Hard refresh option (`bypassCache`).
- Start/stop from the popup, the `Alt+Shift+R` shortcut, or the toolbar icon context menu.
- Toolbar context menu with quick start intervals.
- Automatic cleanup when a tab closes; clear error state and `!` badge on failure.
- English and Turkish UI, following the Firefox interface language.
- Dark and light themes.
- No telemetry, no analytics, no network requests.
